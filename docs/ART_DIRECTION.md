# AgentFoundry Artwork Direction

This document defines the visual language for promotional art, splash screens, README heroes and release graphics.

## Core concept

**A future forge for local intelligence.**

Ancient Roman visual discipline meets local AI infrastructure.

The artwork should feel:

- monumental
- intelligent
- controlled
- technical
- premium
- mysterious without becoming fantasy-heavy

## Primary composition

Preferred wide hero composition:

- AgentFoundry product UI centered
- one male and one female digitized classical deity framing the UI
- dark monumental architecture in the background
- subtle arches / columns / carved stone
- restrained celestial diagrams and orbit lines
- gold light on one side, cool azure light on the other
- ample negative space for the product title

The deities support the product visually; they must not overpower the UI.

## Digital deity treatment

Figures should look like believable classical sculpture translated into a technological medium.

Use:

- marble / bronze / dark stone surfaces
- subtle glowing circuitry
- translucent holographic layers
- geometric constellation maps
- fine data lines
- restrained luminous eyes only when appropriate

Avoid:

- superhero poses
- fantasy weapons
- excessive armor
- glowing cyberpunk clutter
- comic-book styling
- overt religious worship scenes

## Male archetype

Visual associations:

- infrastructure
- force
- runtime
- guardianship
- execution

Suggested treatment:

- dark marble or bronze
- amber/gold circuitry
- architectural geometry

## Female archetype

Visual associations:

- knowledge
- model intelligence
- orchestration
- navigation
- insight

Suggested treatment:

- pale marble or dark polished stone
- azure/violet circuitry
- celestial / constellation geometry

## Product UI visibility

When artwork includes the application interface:

- UI should remain the sharpest central element
- controls should be believable but do not generate fake unreadable microtext
- use simplified panels if exact text cannot be rendered correctly
- do not imply features AgentFoundry does not have

## Lighting

Preferred:

- low-key cinematic lighting
- narrow gold rim light
- cool blue secondary light
- restrained volumetric atmosphere
- subtle marble reflections

Avoid heavy bloom that destroys UI readability.

## Materials

Preferred visual materials:

- black marble
- charcoal stone
- aged bronze
- brushed dark metal
- smoked glass
- warm gold inlays
- cool holographic light

## Hero copy

Primary:

**AgentFoundry**

**Forge your local intelligence.**

Secondary:

**Local model management, hardware-aware tuning and agent orchestration.**

## README hero prompt

Create a cinematic widescreen hero image for an open-source desktop application called AgentFoundry. The product UI is centered and clearly readable as a premium dark local-AI control dashboard. Frame the product subtly with one male and one female Roman-inspired digital deity. Their surfaces resemble refined marble and bronze with restrained luminous circuitry and celestial geometry embedded into the sculpture. Use dark monumental architecture, arches and subtle columns in the background, with deep obsidian and midnight-blue tones, sparse imperial-gold accents, cool azure holographic light and controlled atmospheric haze. The composition should feel intelligent, powerful, calm and technical rather than fantasy-heavy. Keep plenty of negative space around the AgentFoundry title and the tagline “Forge your local intelligence.” The product remains the hero; the deities create the mythic atmosphere.

## Splash screen prompt

Create a minimal cinematic splash screen for AgentFoundry, a local AI model and agent manager. Dark obsidian background, faint Roman architectural reliefs, a subtle classical male and female digital figure emerging from shadow at opposite edges, thin gold and azure circuitry, a central geometric forge/core symbol, elegant AgentFoundry wordmark and the tagline “Forge your local intelligence.” Premium, quiet, monumental, highly restrained, no busy interface elements.

## Release artwork prompt

Create a premium release-card image for AgentFoundry. Use a dark technical control-panel aesthetic with restrained Roman marble details, a single sculptural digital deity in the background, subtle gold/azure data lines, and a large clean area for release number and feature highlights. No game aesthetic, no fantasy battle imagery, no fake UI text.

## Product rule

> The software is the instrument. Mythology is the atmosphere.
